# DSP 01：采样、量化与混叠

## 要解决的问题

麦克风得到连续变化的电信号，而程序处理的是数值序列。采样把时间离散化，量化把幅度离散化。理解这两步，才能正确设置录音参数与模型输入。

先修知识：正弦波的频率、周期和幅度。

## 采样率决定时间间隔

采样率 fs 的单位是 Hz，表示每秒采样次数。采样间隔 Ts = 1 / fs。

连续信号 x(t) 采样后得到 x[n] = x(n / fs)，n 是整数索引。

例如 16 kHz 音频每秒有 16000 个采样点，20 ms 的一帧有 320 个点。模型要求 16 kHz 时，48 kHz 录音需要重采样；只修改文件头会同时改变播放速度和音高。

## 混叠为什么发生

对于最高频率为 B 的理想带限基带信号，采样率应满足 fs > 2B，才能在理想条件下重建。fs / 2 是奈奎斯特频率。

实际模拟滤波器有过渡带，因此应留出余量，并在 ADC 采样前进行抗混叠低通滤波。混叠已经发生后，数字滤波无法恢复原来无法区分的频率。

以 fs = 8000 Hz 为例，1000 Hz 与 7000 Hz 余弦波在整数采样时刻得到相同的序列：

`cos(2π × 7000 × n / 8000) = cos(2π × 1000 × n / 8000)`

因此「8 kHz 采样能记录 7 kHz 音频」是错误的；此例会折叠成 1 kHz。

## 量化与 PCM

B 位整数共有 2^B 个编码。16 位有符号 PCM 的取值范围是 -32768 到 32767。

对幅度范围近似为 [-1, 1) 的均匀量化器，步长 Δ = 2 / 2^B；未发生过载、采用最近值舍入时，误差幅度通常不超过 Δ / 2。削波时不再满足这个误差界限。

理想均匀量化器对满幅正弦波的信噪比近似为 6.02B + 1.76 dB。这个估计依赖信号与量化噪声假设，不等于真实麦克风的信噪比。

未压缩 PCM 码率 = 采样率 × 位深 × 声道数。16 kHz、16 位、单声道为 256 kbit/s，即每秒 32000 字节，不含文件头。I2S 的槽位宽度可能大于有效位深，不能直接用这个公式推断 BCLK。

## 小实验：验证混叠

以下代码只使用 Python 标准库：

```python
import math

fs = 8000
a = [math.cos(2 * math.pi * 1000 * n / fs) for n in range(32)]
b = [math.cos(2 * math.pi * 7000 * n / fs) for n in range(32)]
error = max(abs(x - y) for x, y in zip(a, b))
print("最大误差：", error)
assert error < 1e-12
print("20 ms 帧长：", fs * 20 // 1000)
```

预期：最大误差接近浮点舍入误差，帧长为 160。这个实验验证离散序列无法区分上述两个频率，不模拟真实 ADC 的模拟滤波器。

## 自测

1. 48 kHz 音频一帧 10 ms 有多少点？答：480。
2. 16 位改成 24 位能消除混叠吗？答：不能，位深影响幅度量化。
3. 降采样前为什么要低通？答：抑制新奈奎斯特频率以上的成分，避免折叠进目标频带。
