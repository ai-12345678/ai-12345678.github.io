## 要解决的问题

识别一段声音是否包含唤醒词，可以手写规则，也可以让模型从标注样本中学习。先理解模型训练与评估，才能判断模型是否适用于真实设备。

## AI、机器学习与深度学习

人工智能是一个广泛领域；机器学习关注从数据中学习规律；深度学习主要使用多层神经网络。三者存在包含关系，但 AI 不只有神经网络。

DSP 提供采样、滤波和频谱等信号处理方法。传统 DSP 与学习模型经常协作，例如「音频 → Mel 频谱 → 神经网络 → 唤醒结果」。也有模型直接接收波形，具体输入以模型约定为准。

## 训练流程

1. 明确任务：例如每段音频是否含目标关键词。
2. 收集并标注数据，同时记录说话人、设备、场景。
3. 拆分训练集、验证集和测试集。
4. 用训练集更新模型参数，用验证集选择超参数与阈值。
5. 冻结方案，在测试集评估泛化能力。
6. 部署时继续观察真实环境的误触发与漏检。

训练集用于学习；验证集用于选择；测试集用于最终评估。反复根据测试结果调整模型，会削弱测试集作为独立评估的价值。

同一说话人或同一录音切出的相近片段进入不同集合，可能造成数据泄漏。应根据部署目标按说话人、录音会话或设备分组拆分。归一化等预处理统计量也应从训练集估计。

## 一个最小数学模型

线性模型分数为 z = w·x + b；二分类可用 sigmoid 得到 p = 1 / (1 + exp(-z))。

训练通过损失函数衡量预测与标注差异，再调整 w、b。对于二元标签 y，交叉熵为：

`L = -[y log(p) + (1-y) log(1-p)]`

实践中通常直接使用基于 logits 的数值稳定实现。训练并不是背下这条公式，而是让参数在训练数据上降低损失，同时通过独立数据检查是否过拟合。

## 为什么不能只看准确率

假设 1000 段录音中只有 10 段含唤醒词。始终预测「没有」的准确率达到 99%，却一个关键词也检测不到。

| 指标 | 公式 | 关注什么 |
| --- | --- | --- |
| 精确率 Precision | TP / (TP + FP) | 触发的结果有多少正确 |
| 召回率 Recall | TP / (TP + FN) | 真实正例找到了多少 |
| F1 | 2TP / (2TP + FP + FN) | 精确率与召回率的综合 |
| 准确率 Accuracy | (TP + TN) / 总数 | 所有样本判对的比例 |

TP 是正确检出，FP 是误报，FN 是漏检，TN 是正确拒绝。指标分母为零时需要明确约定。

唤醒词系统还应记录每小时误触发次数、事件级漏检率、延迟和设备功耗。窗口级指标与事件级指标不可直接互换。

## 小实验：计算指标

```python
tp, fp, fn, tn = 8, 2, 2, 988
precision = tp / (tp + fp)
recall = tp / (tp + fn)
accuracy = (tp + tn) / (tp + fp + fn + tn)
f1 = 2 * tp / (2 * tp + fp + fn)
print(f"precision={precision:.3f}, recall={recall:.3f}")
print(f"accuracy={accuracy:.3f}, f1={f1:.3f}")
```

预期：精确率、召回率和 F1 都是 0.800，准确率是 0.996。降低检测阈值通常增加召回率，也可能增加误报；应在相同验证数据上比较，不保证每次调节都会严格变化。

## 自测

1. 训练损失下降是否证明实际效果提升？答：不能，还需独立评估。
2. 阈值应该在哪个集合上选择？答：验证集。
3. 连续运行语音设备为什么记录误触发/小时？答：它更直接反映长时间使用时的干扰程度。
