## 1. 一张图理解声音链路

```text
声音播放：
数字 PCM → ESP32/I2S → DAC/Codec → 功放 ← 电源
                                 ↓
                            扬声器振膜振动
                                 ↓
                       空气声波（物理声学）
                    ├─ 声压 / 声压级（Pa / dB SPL）
                    ├─ 频率 / 频谱（Hz）
                    └─ 声强 / 声功率（W/m² / W）
                                 ↓
                            人耳与大脑
                    ├─ 响度：感觉有多响
                    ├─ 音调：感觉有多高
                    └─ 音色：听起来是什么质感

声音采集：
空气声波 → 麦克风 → ADC/Codec → PCM → AFE/DSP → VAD/KWS/ASR
```

理解重点：**客观物理量**与**主观听觉感受**不同；**数字信号电平**与**实际空气中的声压级**也不同。

## 2. 物理声学：声压、声压级、声强、声功率

### 2.1 声压（Sound Pressure）

声音是介质中的压力扰动。声压 `p(t)` 表示相对于静态环境压力的变化，单位为 **Pa（帕）**。通常使用一段时间内的均方根声压 `p_RMS` 表示有效大小。

### 2.2 声压级（Sound Pressure Level，SPL）

空气中的参考声压通常为 `p₀ = 20 μPa`，声压级为：

\[
L_p=20\log_{10}\left(\frac{p_{\mathrm{RMS}}}{p_0}\right)\quad\mathrm{dB\ SPL}
\]

- 声压增加 2 倍：声压级约 **+6 dB**。
- 声压增加 10 倍：声压级 **+20 dB**。
- 声压级不是绝对不变的设备属性；它取决于**测量位置、距离、方向、频率与环境**。
- 声压计用于测量声压级；必须记录 A/Z 计权、快/慢时间计权和测量距离等条件。

典型声压级仅供形成直觉：安静室内约 30–40 dB SPL、普通交谈约 60 dB SPL、较响的街道约 80 dB SPL；实际值受环境和距离影响很大。

### 2.3 声强（Sound Intensity）

声强表示穿过单位面积的**声功率流密度**，单位 **W/m²**，有方向。对于自由场中的平面行波，可近似使用 `I = p_RMS²/(ρc)`；这一关系**不能直接照搬到任意近场或复杂反射环境**。

### 2.4 声功率（Sound Power）

声功率表示声源辐射到声场中的声学能量速率，单位 **W**。它不同于扬声器输入的电功率：扬声器的电能只有一部分转化为声能，其余可变为热和其他损耗。

| 术语 | 描述 | 单位 | 是否与测点相关 |
|---|---|---|---|
| 声压 | 某位置空气压力的变化 | Pa | 是 |
| 声压级 | 相对参考声压的对数值 | dB SPL | 是 |
| 声强 | 单位面积的声能流率 | W/m² | 是，且有方向 |
| 声功率 | 声源辐射的总声学功率 | W | 作为声源量，在规定条件下测定 |
| 扬声器输入电功率 | 功放送入扬声器的电功率 | W | 不是声功率 |

## 3. 听觉感知：音量、响度、音调、音色

### 3.1 音量（Volume）

“音量”是日常和产品 UI 中对声音大小的泛称。设备的“音量 60%”通常只是某个**数字幅度系数或增益档位**，不是标准的 60 dB SPL，也不意味着输出功率是额定功率的 60%。

### 3.2 响度（Loudness）

响度是人耳对“有多响”的主观感受，受**声压级、频率、持续时间、频谱和听觉特性**等因素影响。

- **sone**：响度单位。
- **phon**：响度级单位。
- 两个同为 60 dB SPL 的不同频率纯音，可能听起来响度不同。
- **dB(A)** 采用 A 频率计权来衡量声压级；它不是响度（sone）的同义词。

### 3.3 音调（Pitch）

音调表示主观感觉的声音高低。纯音的音调与频率联系紧密；复杂周期音的音调通常与**基频 F0**相关，甚至在缺失基频时仍可能感知到对应音调。

### 3.4 音色（Timbre）

音色回答“同样的音高和响度，为什么钢琴、人声和小提琴听起来不同？”音色与谐波结构、频谱包络、瞬态、起音、衰减、噪声成分等有关。

### 3.5 音长、节奏和语速

- **音长 / 时长（Duration）**：一次发声持续多久，常用 ms、s。
- **节奏（Rhythm）**：声音事件在时间上的组织。
- **语速**：单位时间的发音量；语音 ASR、端点检测和对话系统需要考虑停顿与语速。

| 物理或信号特征 | 对应的主观感知（非一一对应） |
|---|---|
| 声压幅度、频谱和时长 | 响度 |
| 基频、谐波周期性 | 音调 |
| 谐波与噪声分布、包络、瞬态 | 音色 |
| 持续时间与事件时序 | 音长与节奏 |

## 4. 波形特征：振幅、频率、相位、时长与频谱

### 4.1 振幅（Amplitude）

波形偏离零点或平衡位置的程度。需要注明对象：可以是电压振幅、声压振幅，也可以是归一化 PCM 采样幅度。

### 4.2 频率（Frequency）

周期信号每秒完成的周期次数，单位 Hz。频率为 `f` 时，周期 `T=1/f`；例如 1 kHz 的周期是 1 ms。人类典型可听频率范围约 20 Hz–20 kHz，但因人而异。

### 4.3 相位（Phase）与时差

相位描述周期信号在一个周期中的位置，多路麦克风信号的相位关系与时延关系可用于**波束形成、声源定位和空间滤波**。

### 4.4 频谱（Spectrum）

频谱表示音频包含哪些频率成分，以及各频率成分的大小。FFT 可把时域信号转换为频域表示，STFT 则将分帧与傅里叶变换结合，得到随时间变化的频谱。

- **基频 F0**：周期信号的主要周期对应的频率。
- **谐波（Harmonics）**：理想周期信号中基频整数倍的成分。
- **频谱包络**：描述频谱总体起伏，可反映共振峰和音色特征。
- **时频图 / 声谱图（Spectrogram）**：横轴时间、纵轴频率、颜色或亮度表示幅度/功率。

## 5. 数字音频：PCM、RMS、Peak、dBFS、LUFS

| 概念 | 定义 | 常见用途 |
|---|---|---|
| PCM | 采样后的数字波形数据 | ESP32/I2S、录音、ASR 输入 |
| 采样率 | 每秒样本数（如 16 kHz、48 kHz） | 频带和处理吞吐 |
| 位深 | 每个采样值的量化位数（如 16-bit） | 量化精度与理论动态范围 |
| 声道数 | 独立音频通道数量 | 单声道、立体声、麦克风阵列 |
| Peak | 一段信号中的最大幅度 | 判断削波风险 |
| RMS | 均方根幅度 | 测量有效信号电平 |
| dBFS | 相对数字满刻度的电平 | WAV/PCM 电平检查 |
| LUFS | 按标准进行响度加权的节目响度 | 播放响度归一化 |

### 5.1 dBFS 与 dB SPL 的关键区别

- **dBFS** 的参照是数字系统的满刻度；数字正弦的峰值达到满刻度附近时有削波风险。
- **dB SPL** 的参照是空气中的 20 μPa 声压。
- **LUFS** 衡量音频节目的加权响度，通常与 `-16 LUFS` 之类的目标一起使用。
- `-12 dBFS` 的音频**无法直接换算**成某个 `dB SPL`：必须知道 DAC 输出电平、增益、功放、扬声器灵敏度、频响和测量距离。

### 5.2 分贝用于表达不同的“比值”

功率比：

\[
\Delta L=10\log_{10}(P_2/P_1)
\]

同阻抗条件下的电压幅度比：

\[
\Delta L=20\log_{10}(V_2/V_1)
\]

- 功率翻倍：约 **+3 dB**。
- 功率变成 10 倍：**+10 dB**。
- 电压幅度翻倍（同阻抗）：约 **+6 dB**。

这些描述的是不同的量，不能把 dB、dBFS、dB SPL、LUFS 混为一谈。

## 6. 音质与电声系统指标

| 指标 | 含义 | 应用 |
|---|---|---|
| 频率响应 | 不同频率的输入对应多大输出 | 麦克风、扬声器、Codec 评测 |
| SNR（信噪比） | 信号功率与噪声功率比 | 麦克风、音频通路 |
| THD（总谐波失真） | 谐波失真相对于基波的比例 | 功放、扬声器 |
| THD+N | 谐波失真和噪声的组合指标 | 电声设备综合评价 |
| 动态范围 | 可用最大信号与最小有效信号的范围 | ADC/DAC、录音系统 |
| 底噪 / 自噪声 | 系统在无有效输入时的噪声 | 麦克风、前级与电源设计 |
| 失真 / 削波 | 输出偏离目标波形或受到限幅 | 检查大音量音频 |
| 延迟（Latency） | 输入到输出的时间差 | 实时语音通话与唤醒响应 |
| 扬声器灵敏度 | 特定输入和距离下的声压级 | 对比扬声器可实现的音量 |
| 最大声压级 | 限定失真等条件下的最大声压级 | 扬声器与整机播放能力 |

常见灵敏度写法：`85 dB SPL @ 1 W / 1 m`。在线性、相同测量条件下，粗略估算为：

\[
SPL(P)\approx SPL(1W)+10\log_{10}(P/1W)
\]

实际扬声器受热压缩、失真、箱体、房间声学等影响，不能无限按此公式外推。

## 7. 空间声学与麦克风阵列

| 指标/术语 | 说明 | 相关算法 |
|---|---|---|
| 反射 | 声波遇到边界发生传播方向变化 | 房间声学 |
| 回声（Echo） | 可分辨的延迟反射，或播放音频经回采进入麦克风的成分 | AEC |
| 混响（Reverberation） | 多次反射叠加形成的声音拖尾 | 去混响、远场 ASR |
| RT60 | 声场衰减 60 dB 所需时间 | 混响测量 |
| TDOA | 声音到达不同麦克风的时间差 | 声源定位 DOA |
| 相位差 | 不同麦克风对同一声源的相位差 | 波束形成 Beamforming |
| 指向性 | 麦克风或扬声器对方向的敏感程度 | 麦克风阵列、定向播放 |
| ERLE | 回声消除前后回声能量衰减能力的常用指标 | AEC 评测 |

一个典型的多麦克风语音链路：

```text
Mic 1 / Mic 2 / ... / Mic N ──┐
                                ├─ ADC / PDM / I2S ──► AFE
SPK Reference（播放参考） ───────┘                      ├─ AEC 回声消除
                                                       ├─ Beamforming 波束形成
                                                       ├─ NS 降噪
                                                       └─ AGC 自动增益
                                                            ↓
                                                        VAD / KWS / ASR
```

说明：AEC、NS、AGC 的实际先后与耦合方式取决于具体算法架构；**多个 PCM 声道不一定都是物理麦克风**，也可能包含播放回采 reference 通道。

## 8. ESP32、Codec、功放与扬声器原理

### 8.1 核心问题：同一对扬声器线为什么既能传声音又能传能量？

音频信号是随时间变化的电压和电流。**信号波形**编码声音信息，**电压和电流共同向负载传输能量**。这不是给“数据线”额外叠加一套独立直流供电，而是功率放大器输出具有相应波形与功率的电信号。

对于纯电阻近似：

\[
i(t)=v(t)/R,\quad p(t)=v(t)i(t)\]

例：对理想 `4 Ω` 电阻负载施加 `2 V RMS` 正弦波，得到 `0.5 A RMS` 和 `1 W` 平均功率。真实扬声器不是纯电阻：音圈电感、运动反电动势与频率相关阻抗都会影响电压、电流关系。

音圈处于磁场中时，电流使其受到方向和大小随电流变化的电磁力，驱动振膜推动空气。电流瞬间通过零点是正常的，并非“扬声器断电”；振膜仍可能依靠机械惯性继续运动。

### 8.2 无源扬声器与有源音响

**无源扬声器：**

```text
ESP32 ──I2S──► MAX98357A（DAC + D 类功放） ──SPK+/SPK−──► 无源喇叭
                           ▲
                         5V 电源
```

**有源音响：**

```text
ESP32 ──I2S──► DAC / Codec ──模拟 Line Out──► 有源音响的 Line In
                                               ├─ 内置功放
                                               └─ 外接 12V 等电源
```

共同点：**功放都必须从电源获得驱动所需的能量**。区别只是功放是在外部模块，还是内置于有源音响里。

注意：常见 BTL 桥接功放的 `SPK−` 是主动驱动端，**不是 GND**，不得随意接地。外接电源需要匹配具体功放芯片的允许供电范围。

### 8.3 外接电源不是直接“放大音频”

DAC/Codec 输出的是波形信息，通常只具备较弱的带载能力；功放**用外部电源的能量**，受音频信号控制，形成足够大的输出电压和电流。

- 电源提供能量。
- 功放完成受音频调制的功率转换与放大。
- 扬声器把电能转成机械振动和声能。

### 8.4 不是恒功率驱动

音频输出电压与电流动态变化，因此瞬时电功率一般也变化，不存在“保持 W 不变、只改变电压播放音频”的规则。**电流随音乐变小是正常的；当功放无法满足所需的峰值电压/电流时，才可能发生削波、失真或保护。**

### 8.5 5V 为什么限制最大音量？

5V 限制功放可实现的电压摆幅，而供电、芯片、负载与热设计也限制输出电流和平均功率。以**理想 5V BTL 正弦输出、4Ω 电阻负载**估算：

\[
V_{\mathrm{RMS}}\le 5/\sqrt2\approx3.54\,V,\quad P\le3.125\,W
\]

这是理想模型，不等于任一功放实测额定功率。最大 dB SPL 还取决于扬声器灵敏度、频率、失真、箱体、距离与环境。某些标称 5V 输入的有源音响内部可能还有升压电路。

## 9. 语音设备评测项目与工具

| 评测目标 | 推荐指标 | 工具或方法 |
|---|---|---|
| 最大播放响度 | dB SPL、最大 SPL、失真阈值 | 校准声压计，固定距离与测试音 |
| 扬声器音质 | 频率响应、THD、THD+N | 测量麦克风、音频分析工具 |
| 录音电平 | RMS、Peak、dBFS | Audacity、Python、FFmpeg |
| 录音底噪 | 噪声谱、RMS、SNR | 安静环境录音、频谱分析 |
| AEC 性能 | ERLE、残余回声、双讲表现 | 回采参考通道、AEC 前后对比 |
| 降噪效果 | SNR 改善、语音失真、主观听感 | 录音对比、频谱分析 |
| VAD 性能 | 误检率、漏检率、端点延迟 | 标注数据集 |
| KWS 性能 | 唤醒率、误唤醒率、不同声压/距离 | 唤醒测试集 |
| ASR 性能 | WER/CER、不同 SNR 的错误率 | 标注语音及识别输出 |
| 声源定位 | 方位角误差 | 多麦克风阵列、已知声源方向 |

### 9.1 推荐的一次完整基础实验

1. 使用 `arecord` 或板卡驱动录制 16 kHz PCM/WAV，确认采样率、位深和声道数。
2. 使用 Audacity 查看波形、频谱与频谱图，确认静音、峰值、噪声分布。
3. 播放频率为 1 kHz 的测试音，固定距离使用声压计记录 dB SPL。
4. 在不同数字增益下重复测量：比较 dBFS、声压级与可闻失真，**不要假设它们存在固定换算**。
5. 若启用 AEC，同时录制麦克风原始通道、AEC 输出和播放 reference，观察残余回声。
6. 记录设备电源电压、功放型号、扬声器阻抗/灵敏度、测量位置和环境，保证结果可复现。

### 9.2 常见命令

查看音频元数据：

```bash
ffprobe -hide_banner -show_streams -select_streams a:0 sample.wav
```

播放测试音（示例：1 kHz、5 秒、16 kHz 单声道 WAV；使用适当增益，不要直接以最大音量播放）：

```bash
ffmpeg -f lavfi -i 'sine=frequency=1000:sample_rate=16000:duration=5' -c:a pcm_s16le test-1k.wav
ffplay -autoexit test-1k.wav
```

录音（设备名、参数按实际 ALSA 配置调整）：

```bash
arecord -D default -f S16_LE -r 16000 -c 1 -d 10 record.wav
```

## 10. 速查表与常见误区

| 用户说法 / 问题 | 更准确的理解 |
|---|---|
| “分贝就是音量” | dB 是对数比值；dB SPL 才是相对参考声压的声压级 |
| “音量越高，响度一定按比例增加” | 主观响度与声压级、频率、时长等共同相关 |
| “功放标 3W，就一直输出 3W” | 3W 是规定条件下的输出能力/额定指标，实际输出随音频变化 |
| “无源喇叭不用电源” | 它从外部功放的扬声器输出线获得驱动能量 |
| “有源音响的外接电源直接放大波形” | 放大由功放电路完成，电源提供能量 |
| “输出电流瞬间很小，会不会断电” | 正常音频电流本来就在变化；只有超出功放输出能力才有问题 |
| “5V 音响最多是多少 dB” | 无法仅凭 5V 判断，还取决于功放、扬声器、失真与测量条件 |
| “-12 dBFS 的音频是 -12 dB SPL” | 数字电平与空气中的声压级基准不同，不可直接换算 |
| “8 声道录音说明有 8 个麦克风” | 声道可能包含播放回采 reference、处理结果或其他数据 |
| “AUX 能直接接无源扬声器” | AUX/Line Out 一般是小信号接口，无源扬声器通常需要功放 |

### 最终记忆框架

- **Hz ↔ 音调**：频率影响声音高低。
- **Pa / dB SPL ↔ 响度**：前者是客观声压，后者是主观感知。
- **谐波 / 频谱 / 瞬态 ↔ 音色**：决定不同声源听起来的差异。
- **W（电功率） → 扬声器 → dB SPL**：电功率经换能形成声场，两者不能直接等同。
- **dBFS / RMS / Peak**：判断数字音频电平与削波。
- **SNR / THD / 频率响应 / 延迟**：判断录音与播放通路质量。
- **TDOA / 相位 / 混响 / ERLE**：连接空间声学与 AEC、波束形成、声源定位。

**进一步学习顺序**：波形与采样 → FFT / STFT → 频谱与 Mel → SNR / 滤波 → AEC / NS / AGC → VAD / KWS / ASR → 电声与整机评测。
