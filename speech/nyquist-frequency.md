# 奈奎斯特频率（Nyquist Frequency）

## 1. 基本概念

**奈奎斯特频率 = 采样率的一半。**

~~~text
f_N = f_s / 2
~~~

- **信号频率（f）**：声音（如正弦波）每秒振动的次数，单位 Hz。
- **采样率（f_s）**：ADC 每秒采集的采样点数量，单位 Hz。
- **奈奎斯特频率（f_N）**：无混叠采样所允许的最高频率边界。

例如，麦克风采用 **16 kHz 采样率**，奈奎斯特频率就是 **8 kHz**。这不是说所有 8 kHz 以下的声音都能被设备毫无衰减地录下；实际还受到麦克风频响、滤波器等影响。

## 2. 采样率与声音频率的关系

**采样率决定能够记录多高频率的声音，不会直接改变原本声音的频率。**

例如，音箱播放一个 **10 kHz 正弦波**：

- 音箱发出的原始声波依然是 10 kHz，与麦克风如何采样无关。
- 麦克风以 **48 kHz** 采样时，可以无混叠地记录这个频率。
- 麦克风以 **16 kHz** 采样时，如果没有抗混叠滤波，10 kHz 会在 PCM 频谱中表现为 6 kHz。
- **原始声音并未变为 6 kHz**，只是采样后无法区分原来的高频信号与较低频率的信号。

对于最高频率为 f_max 的理想带限信号，常用采样定理条件为：

~~~text
f_s > 2 × f_max
~~~

每个正弦波周期的**平均**采样点数为：

~~~text
N = f_s / f
~~~

假设原始正弦波的频率为 **10 kHz**：

| 麦克风采样率 | 每周期平均采样点 | 结果（假设采样前未滤波） |
| --- | ---: | --- |
| 16 kHz | 1.6 | 发生混叠，频谱峰值出现在 6 kHz |
| 20 kHz | 2 | 奈奎斯特边界，依赖采样相位，不能可靠重建 |
| 24 kHz | 2.4 | 理论上可正确重建 |
| 48 kHz | 4.8 | 可正确重建 |
| 96 kHz | 9.6 | 可正确重建，波形采样点更密集 |

这里的“1.6 个点”是**每周期平均值**，不表示 ADC 能采集小数个点。理想重建也不要求每个周期一定有 8～10 个点；更密集的采样主要让直接绘制的波形更容易观察。

另外，**播放文件的采样率、声音本身的频率、麦克风录音的采样率**是不同参数：48 kHz 的 WAV 文件可以包含 10 kHz 的声音，而麦克风可以独立选择 16 kHz 或 48 kHz 录音。

## 3. 人耳能够听到的声音频率

人耳典型可听范围约为 **20 Hz～20 kHz**，实际范围因年龄、个体差异和听力状态而不同。

| 声音频率 | 人耳能否听到 |
| --- | --- |
| 20 Hz～200 Hz | 能，低频声音 |
| 200 Hz～4 kHz | 能，人声的重要频率范围 |
| 4 kHz～8 kHz | 能，高频声音 |
| 8 kHz～16 kHz | 通常能听到，但高频敏感度逐渐下降 |
| 16 kHz～20 kHz | 部分人能听到，尤其是年轻人 |
| 超过 20 kHz | 通常听不到，属于超声波 |

**与采样率的关系：**

- **16 kHz 采样率**：奈奎斯特频率为 8 kHz，常用于语音识别（ASR）。
- **44.1 kHz 采样率**：奈奎斯特频率为 22.05 kHz，可以覆盖典型人耳可听频带。
- **48 kHz 采样率**：奈奎斯特频率为 24 kHz，常用于音视频制作与音频设备。

奈奎斯特频率是数学上的频率边界，实际系统需要给抗混叠滤波器留出过渡带。

## 4. 什么是混叠（Aliasing）？

**混叠是指输入信号包含超出奈奎斯特频率的成分，而采样前没有充分抑制这些成分，导致高频信号在 PCM 中表现为错误的低频信号。**

例如：

- 原始正弦波：10 kHz。
- 麦克风采样率：16 kHz。
- 奈奎斯特频率：8 kHz。
- 混叠后的频率：6 kHz。

该例中可以这样计算：

~~~text
f_alias = |f_signal - f_s|
        = |10000 - 16000|
        = 6000 Hz
~~~

这是本例适用的计算形式；一般情况下，混叠频率会折叠到 0～f_s/2 范围内。

**频谱对比：**

~~~text
原始模拟信号：  10 kHz 正弦波
                    │
                    ▼
没有抗混叠滤波，16 kHz 采样
                    │
                    ▼
PCM 的频谱：      6 kHz 处出现峰值
~~~

这不是改变了空气中声波的振动频率，而是采样点不足以区分这些不同的模拟频率。采样后已经混叠在一起的信号，通常无法仅靠普通数字滤波准确分离。

## 5. 如何避免混叠？

**方式一：提高采样率。** 例如，采集 10 kHz 的正弦波可以选用 24 kHz、48 kHz 或更高采样率。

**方式二：采样前低通滤波。** 在 ADC 之前使用抗混叠滤波器，抑制高于目标奈奎斯特频率的成分。例如，使用 16 kHz 采样率时，需要提前衰减接近或高于 8 kHz 的高频成分，并预留实际滤波器的过渡带。

**数字降采样也一样：** 把 48 kHz PCM 转换为 16 kHz PCM 时，应先对数字信号进行抗混叠低通滤波，再减少采样点，不能直接每隔 3 个点取 1 个而不考虑高频成分。

## 6. 总结

1. **奈奎斯特频率 = 采样率 ÷ 2。**
2. **采样率决定能够记录的最高声音频率，不会直接改变原本声音的频率。**
3. 对理想带限信号，采样率应大于信号最高频率的两倍，才满足常见的无混叠采样条件。
4. 人耳典型可听范围约为 20 Hz～20 kHz；44.1 kHz 和 48 kHz 采样率能覆盖该范围。
5. 混叠使高频成分在 PCM 中表现为错误的低频成分。
6. 提高采样率和在采样（或降采样）前进行抗混叠低通滤波，可以避免混叠。

**语音工程示例：** ASR 常使用 16 kHz PCM，其奈奎斯特频率为 8 kHz，所以录音或降采样时，需要抑制目标带宽以外的高频信号。
