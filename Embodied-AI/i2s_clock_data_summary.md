# I2S 时钟与数据基础

## 1. 脉冲

脉冲：电平从一种状态跳到另一种状态，维持一段时间，再回来。

重点关注：
- 上升沿
- 下降沿
- 脉冲宽度

```text
____|‾‾‾‾|____
    <---->
     脉冲
```

## 2. 时钟

时钟本质上是数字系统的**节拍器 / 时间基准**。

主要作用：

> 告诉接收方什么时候读取数据。

## 3. I2S 三个关键信号

- **BCLK（Bit Clock）**：控制每个 bit 的读取节奏。
- **WS / LRCLK（Word Select / Left-Right Clock）**：控制一组 bit 属于哪个 word / 声道，例如 Left / Right。
- **DATA**：承载真正的 PCM 0 / 1 数据。

一句话记忆：

> **BCLK 管节拍，WS 管分组，DATA 管内容。**

## 4. BCLK 与 DATA 的关系

通常，DATA 每传输 1 个 bit，BCLK 提供一个对应的时钟周期。

```text
BCLK:  ↑   ↑   ↑   ↑
DATA:  1   0   1   1
```

接收端在约定的 BCLK 边沿读取 DATA。

## 5. 时序要求

Clock 和 DATA 不需要完全同时变化，实际电路中通常会存在：

- 传播延迟
- skew（偏斜）
- jitter（抖动）

关键要求是：

> **在可能采样的时间窗口内，DATA 必须保持稳定。**

```text
          采样窗口
         <------->
DATA: ---111111111---
```

如果 DATA 恰好在采样附近变化，就可能：

- 读成 0
- 读成 1
- 出现亚稳态

## 6. 最终记忆

> **DATA 决定“传什么”，BCLK 决定“什么时候读”，WS/LRCLK 决定“这组数据属于谁”。**
